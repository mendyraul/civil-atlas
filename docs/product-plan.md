# Product Plan

## Vision

Build a time-aware historical atlas where users can move through years and see
civilizations, places, routes, and evidence-backed claims change together.

## MVP

- Atlas view with timeline slider
- Active civilization layers by year
- Zoom-aware places and routes
- Clickable detail panels
- Canonical backend data model with sources and evidence links
- Small manual seed focused on `117 CE`

## Future phases

- Reviewed geometry and richer boundary variants
- More regions, places, and route types
- External importers for datasets like Pleiades and WHG
- Review workflow, audit history, and editor tooling
- PostGIS-backed geometry, tiles, and deeper globe performance work
